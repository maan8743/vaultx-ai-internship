# ROI Analysis: Expense Tracking Automation

| Metric | Manual Process | Automated Process |
|---|---|---|
| Time per receipt | 2-3 minutes | 10-15 seconds |
| Time for 20 receipts/month | ~50 minutes | ~4 minutes |
| Monthly time saved | — | ~46 minutes |
| Cost per receipt (API) | $0 (but time cost) | <$0.01 |
| Categorization consistency | Variable | Consistent |
| Data loss rate | Receipts commonly lost/forgotten | Near-zero (camera always available) |
| Query time ("how much did I spend on X") | 2-5 minutes (manual filtering) | ~5 seconds |

## Summary
At 20 receipts/month, this automation saves approximately 46 minutes of manual
entry time, for a marginal cost of under $0.20/month in API usage — while also
improving data consistency and eliminating the "I forgot to log it" failure
mode entirely.
